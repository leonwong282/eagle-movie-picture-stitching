# 🤝 行為準則

## 我們的承諾

我們致力於為所有貢獻者和參與者提供友善、安全且熱情的環境，無論其經驗水平、性別認同與表達、性傾向、身心障礙、外表、體型、種族、族裔、年齡、宗教、國籍或其他受保護特徵為何。

## 我們的標準

### 正面行為 ✅

- 使用友善且包容的語言
- 尊重不同的觀點和經驗
- 優雅地接受建設性的批評
- 專注於對社群最有利的事情
- 對其他社群成員表示同理心
- 對新手和問題保持耐心

### 不可接受的行為 ❌

- 使用性暗示的語言或圖像
- 人身攻擊、挑釁或侮辱性評論
- 公開或私下騷擾
- 未經許可發布他人的私人資訊
- 垃圾訊息、自我宣傳或離題內容
- 其他可合理認為不當的行為

## 執行

### 回報

如果您經歷或目睹不可接受的行為，請透過以下方式回報：

- **電子郵件**：[leonwong282@gmail.com](mailto:leonwong282@gmail.com)
- **GitHub Issues**：用於關於社群準則的公開討論
- **直接訊息**：直接聯繫專案維護者

所有回報都將被迅速且公正地審查和調查。

### 後果

專案維護者可能採取以下行動：

1. **警告**：私下書面警告
2. **暫時停權**：暫時禁止參與專案
3. **永久封禁**：永久移出專案社群

## 適用範圍

本行為準則適用於所有專案空間，包括：

- GitHub 儲存庫和 issues
- Pull requests 和程式碼審查
- 社群討論和論壇
- 專案活動和會議
- 與專案相關的社群媒體互動
