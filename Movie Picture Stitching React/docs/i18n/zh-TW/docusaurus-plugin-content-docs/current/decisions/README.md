# 架構決策記錄

此目錄包含架構決策記錄（ADR），記錄本專案中做出的重要架構決策。

## 什麼是 ADR？

**架構決策記錄**（ADR）捕捉重要的架構決策及其背景和後果。ADR 有助於：

- 📝 記錄決策背後的「原因」
- 🔄 追蹤專案的演變過程
- 👥 更快地讓新團隊成員上手
- 🔍 避免重複討論已決定的議題

## 建立新的 ADR

1. **複製模板：**
   ```bash
   cp docs/docs/decisions/adr-template.md docs/docs/decisions/adr-XXXX-short-title.md
   ```

2. **編號您的 ADR：**
   - 使用下一個可用的編號（0001、0002 等）
   - 保持編號連續

3. **填寫模板：**
   - 用您的內容替換佔位符
   - 簡潔但完整

4. **更新此索引：**
   - 在上方表格中新增一列

5. **提交 PR：**
   - ADR 應像程式碼一樣被審查

## ADR 狀態

| 狀態 | 含義 |
|------|------|
| **提議中** | 討論中，尚未決定 |
| **已接受** | 決策已做出且生效 |
| **已棄用** | 不再相關但保留作為歷史記錄 |
| **已取代** | 被較新的 ADR 取代 |

## 何時撰寫 ADR

當您遇到以下情況時撰寫 ADR：

- 在多種架構方案之間選擇
- 做出影響整個專案的決策
- 採用新技術或框架
- 更改專案的基本慣例
- 決定不做某事（這些也很有價值！）
