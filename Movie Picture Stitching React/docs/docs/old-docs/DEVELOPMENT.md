## Development Modes

### Option 1: Browser Development (Mock API)

Best for rapid UI iteration without Eagle running:

```bash
npm run dev
# Opens http://localhost:5173
```

**Characteristics:**
- Full Vite HMR (Hot Module Replacement)
- Mock Eagle API with fake data
- No access to real library items
- `eagleApi.isMock === true`

**When to use:**
- Building new UI components
- Styling and layout work
- Testing edge cases with controlled mock data

### Option 2: Eagle Watch Mode (Real API) ⭐ Recommended

Develop with real Eagle data and near-instant rebuilds:

```bash
npm run build:watch
```

Then import the project into Eagle:
1. **Settings** → **Plugins** → **Developer**
2. Click **"Import Local Project"**
3. Select **project root folder** (contains `manifest.json`)
4. Press `Cmd+R` to reload after changes

**How it works:**
```
┌─────────────────────────────────────────────────────────────┐
│  Vite Watch Mode                                            │
│  (npm run build:watch)                                      │
├─────────────────────────────────────────────────────────────┤
│  1. File change detected                                    │
│  2. Vite rebuilds → dist/                                   │
│  3. Press Cmd+R in Eagle                                    │
│  4. Eagle reloads dist/index.html                           │
└─────────────────────────────────────────────────────────────┘
```

**Why this works:** The `manifest.json` points to `dist/index.html`. Eagle reads this path and loads the built output directly.

### Option 3: Production Deployment

```bash
npm run deploy
# Then restart Eagle
```

The deploy script:
1. Builds the project (`npm run build`)
2. Copies files to Eagle plugins directory
3. Transforms `manifest.json` paths (dev → production)
4. Eagle auto-loads on restart

## Eagle API Deep Dive

### Environment Detection

```typescript
import { eagleApi, isEagleEnvironment, hasNodeRequire } from '@/lib/eagle-api';

// Check if running in Eagle
if (isEagleEnvironment()) {
  // Real Eagle API available
  const items = await eagleApi.getSelectedItems();
}

// Check if Node.js require is available
if (hasNodeRequire()) {
  const fs = require('fs');
  const path = require('path');
}
```

### EagleAPIAdapter Architecture

The adapter provides a unified interface for both environments:

```typescript
class EagleAPIAdapter {
  private eagle: EagleAPI | MockEagleAPI;
  
  constructor() {
    this.eagle = isEagleEnvironment() 
      ? window.eagle 
      : createMockEagleAPI();
  }
  
  // All methods work in both environments
  async getSelectedItems(): Promise<Item[]> { }
  async addItemFromPath(path: string, options: AddOptions): Promise<void> { }
  
  // Computed properties
  get isMock(): boolean { }
  get isDarkMode(): boolean { }
  get locale(): string { }
}

// Singleton instance
export const eagleApi = new EagleAPIAdapter();
```

### Selection Polling Pattern

Eagle doesn't push selection updates - you must poll:

```typescript
// useEagleSelection hook implementation
const useEagleSelection = (options = {}) => {
  const { pollingInterval = 500, autoStart = true } = options;
  const [items, setItems] = useState<Item[]>([]);
  
  useEffect(() => {
    if (!autoStart) return;
    
    const checkSelection = async () => {
      const selected = await eagleApi.getSelectedItems();
      // Only update if selection changed (compare IDs)
      if (hasSelectionChanged(items, selected)) {
        setItems(selected);
      }
    };
    
    const interval = setInterval(checkSelection, pollingInterval);
    checkSelection(); // Initial check
    
    return () => clearInterval(interval);
  }, [pollingInterval, autoStart]);
  
  return { items, isLoading, refresh };
};
```

```typescript
// Get selected items
const items = await eagleApi.getSelectedItems();
```

### File Path Handling

Eagle provides both URI and path formats - use the right one:

```typescript
const item = items[0];

// ✅ Use filePath for Node.js fs operations
const absolutePath = item.filePath;  // '/Users/.../image.png'

// ❌ Don't use fileURL for fs operations
const uri = item.fileURL;  // 'file:///Users/.../image.png'

// Convert if needed
const pathFromUri = new URL(uri).pathname;
```

## Component Development with CVA

### Variant Pattern

Use `class-variance-authority` for type-safe component variants:

```typescript
import { cva, type VariantProps } from 'class-variance-authority';
import { cn } from '@/lib/utils';

// Define variants
const buttonVariants = cva(
  // Base classes (always applied)
  'inline-flex items-center justify-center rounded-lg font-medium transition-all focus-visible:outline-none focus-visible:ring-2 disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        default: 'bg-blue-600 text-white hover:bg-blue-500',
        primary: 'bg-gradient-to-r from-emerald-600 to-emerald-700 text-white hover:from-emerald-500 hover:to-emerald-600',
        destructive: 'bg-red-600 text-white hover:bg-red-500',
        outline: 'border border-gray-300 dark:border-gray-600 bg-transparent hover:bg-gray-100 dark:hover:bg-gray-800',
        secondary: 'bg-gray-200 dark:bg-gray-700 text-gray-900 dark:text-gray-100',
        ghost: 'hover:bg-gray-100 dark:hover:bg-gray-800',
        link: 'text-blue-600 underline-offset-4 hover:underline',
      },
      size: {
        sm: 'h-8 px-3 text-xs',
        default: 'h-10 px-4 text-sm',
        lg: 'h-12 px-6 text-base',
        icon: 'h-10 w-10',
      },
    },
    defaultVariants: {
      variant: 'default',
      size: 'default',
    },
  }
);

// Component interface
interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,
    VariantProps<typeof buttonVariants> {
  isLoading?: boolean;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
}

// Component implementation
export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, isLoading, leftIcon, rightIcon, children, ...props }, ref) => {
    return (
      <button
        className={cn(buttonVariants({ variant, size, className }))}
        ref={ref}
        disabled={isLoading || props.disabled}
        {...props}
      >
        {isLoading && <Spinner className="mr-2 h-4 w-4 animate-spin" />}
        {!isLoading && leftIcon && <span className="mr-2">{leftIcon}</span>}
        {children}
        {rightIcon && <span className="ml-2">{rightIcon}</span>}
      </button>
    );
  }
);
```

### The `cn()` Utility

## Theme System Integration

### Eagle Theme Detection

Eagle uses theme constants: `'LIGHT'`, `'DARK'`, `'AUTO'`, `'GRAY'`, `'BLUE'`, `'PURPLE'`

```typescript
// useTheme hook
export const useTheme = () => {
  const [theme, setThemeState] = useState<'light' | 'dark' | 'auto'>('auto');
  
  const isDarkMode = useMemo(() => {
    if (theme === 'auto') {
      // Check Eagle's theme or system preference
      if (isEagleEnvironment()) {
        const eagleTheme = eagleApi.theme;
        return ['DARK', 'GRAY', 'BLUE', 'PURPLE'].includes(eagleTheme);
      }
      return window.matchMedia('(prefers-color-scheme: dark)').matches;
    }
    return theme === 'dark';
  }, [theme]);
  
  // Apply theme to document
  useEffect(() => {
    document.documentElement.classList.toggle('dark', isDarkMode);
  }, [isDarkMode]);
  
  return { theme, isDarkMode, setTheme, toggleTheme };
};
```

## Internationalization (i18n)

### Language Detection Flow

```
┌─────────────────────────────────────────────────────────────┐
│  1. Check window.i18next.language (Eagle's i18next)         │
├─────────────────────────────────────────────────────────────┤
│  2. Fallback: eagleApi.locale                               │
├─────────────────────────────────────────────────────────────┤
│  3. Fallback: navigator.language with mapping               │
├─────────────────────────────────────────────────────────────┤
│  4. Default: 'en'                                           │
└─────────────────────────────────────────────────────────────┘
```

### Language Mapping

```typescript
// src/lib/i18n.ts
const langMap: Record<string, string> = {
  'zh': 'zh_CN',
  'zh-CN': 'zh_CN',
  'zh-TW': 'zh_TW',
  'zh-HK': 'zh_TW',
  'ja': 'ja_JP',
  'ko': 'ko_KR',
  'de': 'de_DE',
  'es': 'es_ES',
  'ru': 'ru_RU',
};

function detectLanguage(): string {
  // Check Eagle's i18next first
  if (window.i18next?.language) {
    return window.i18next.language;
  }
  
  // Check Eagle API
  if (isEagleEnvironment()) {
    return eagleApi.locale;
  }
  
  // Map browser language
  const browserLang = navigator.language;
  return langMap[browserLang] || langMap[browserLang.split('-')[0]] || 'en';
}
```

### Language Change Detection

Eagle doesn't emit language change events - poll periodically:

```typescript
useEffect(() => {
  const checkLanguage = () => {
    const currentLang = detectLanguage();
    if (currentLang !== i18n.language) {
      i18n.changeLanguage(currentLang);
    }
  };
  
  const interval = setInterval(checkLanguage, 2000);
  return () => clearInterval(interval);
}, []);
```

### Storage Key Namespacing

All localStorage keys are prefixed to avoid conflicts:

```typescript
// src/lib/storage.ts
const STORAGE_PREFIX = 'eagle-react-template:';

export const storage = {
  get<T>(key: string, defaultValue: T): T {
    try {
      const item = localStorage.getItem(STORAGE_PREFIX + key);
      return item ? JSON.parse(item) : defaultValue;
    } catch {
      return defaultValue;
    }
  },
  
  set<T>(key: string, value: T): void {
    localStorage.setItem(STORAGE_PREFIX + key, JSON.stringify(value));
  },
  
  remove(key: string): void {
    localStorage.removeItem(STORAGE_PREFIX + key);
  },
};
```

### Selection State Pattern

```typescript
// Centralized selection management
function useSelectionState() {
  const { items } = useEagleSelection();
  const [processedIds, setProcessedIds] = useState<Set<string>>(new Set());
  
  const unprocessedItems = useMemo(
    () => items.filter(item => !processedIds.has(item.id)),
    [items, processedIds]
  );
  
  const markAsProcessed = useCallback((ids: string[]) => {
    setProcessedIds(prev => new Set([...prev, ...ids]));
  }, []);
  
  return { items, unprocessedItems, markAsProcessed };
}
```

## Performance Optimization

### Image Loading

```typescript
// Parallel loading with timeout
async function loadImages(items: Item[]): Promise<LoadedImage[]> {
  const TIMEOUT = 10000; // 10 seconds per image
  
  const promises = items.map(async (item) => {
    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), TIMEOUT);
    
    try {
      const img = new Image();
      img.src = item.filePath;
      await new Promise((resolve, reject) => {
        img.onload = resolve;
        img.onerror = reject;
      });
      return { item, img, success: true };
    } catch (error) {
      return { item, img: null, success: false, error };
    } finally {
      clearTimeout(timeoutId);
    }
  });
  
  return Promise.all(promises);
}
```

### Canvas Size Limits

```typescript
const MAX_CANVAS_SIZE = 32767; // Browser hard limit

function validateCanvasSize(width: number, height: number): void {
  if (width > MAX_CANVAS_SIZE || height > MAX_CANVAS_SIZE) {
    throw new Error(
      `Canvas size ${width}x${height} exceeds maximum ${MAX_CANVAS_SIZE}px`
    );
  }
  
  // Also check total pixels (memory limit)
  const MAX_PIXELS = 268435456; // ~268 million pixels
  if (width * height > MAX_PIXELS) {
    throw new Error('Canvas total pixels exceed memory limit');
  }
}
```

### Debounced Updates


## Troubleshooting

### Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| `window.eagle is undefined` | Running in browser | Use `isEagleEnvironment()` check |
| Changes not appearing in Eagle | Cache | Press `Cmd+R` to reload, or restart Eagle |
| i18n keys showing raw | Translations not loaded | Check `_locales/` files and manifest `languages` array |
| Theme not syncing | Hook not used | Ensure `useTheme()` is called in app root |
| Selection not updating | Polling stopped | Check `useEagleSelection` is mounted |
| Canvas rendering fails | Size too large | Validate dimensions < 32767px |
| localStorage not persisting | Wrong key | Check namespace prefix |

### Debug Checklist

- [ ] DevTools open (`Cmd+Option+I`)
- [ ] Check console for errors
- [ ] Verify `eagleApi.isMock` value
- [ ] Check network tab for failed requests
- [ ] Verify file paths are absolute
- [ ] Check localStorage for saved state
- [ ] Test in browser dev mode first

### Getting Help

1. Check Eagle's official [Plugin API documentation](https://developer.eagle.cool/)
2. Review this template's source code
3. Open DevTools and inspect state
4. Test in browser mode to isolate Eagle-specific issues
